How to Use This Glossary

  1. Identify the specific observable behavior or struggle.
    Not: "Student is bad at math."
    Better: "Student makes frequent calculation errors in multi-digit multiplication."
  2. Type that observation into the search bar above. The glossary matches against problem descriptions, not just strategy names. Try natural language.
  3. Review the matched strategies. Each one shows:
    — What it is and when to use it
    — A ready-to-use teacher script
    — Common mistakes to avoid
    — How to know if it's working
    — Actual research citations
  4. Start with one strategy for 2-3 weeks. Use the progress monitoring suggestion. If no improvement, try the "See also" related strategies or increase dosage.
